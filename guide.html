1. Встановлення Helmy Agent

  1. Завантажте Helmy-Setup.exe з головної сторінки.
  2. Запустіть файл. Якщо Windows показала синє вікно SmartScreen, натисніть «Докладніше» → «Все одно виконати» (програма поки без цифрового підпису видавця).
  3. У майстрі залиште позначені пункти: ярлики й автозапуск з Windows. Права адміністратора не потрібні.
  4. Agent запуститься й оселиться в треї (біля годинника). Закриття вікна лише ховає його в трей; повністю вийти можна через значок у треї → «Вийти».

Оновити Agent: просто запустіть новіший Helmy-Setup.exe — він замінить стару версію, а налаштування збереже. Видалити: «Параметри Windows → Програми» або Helmy-Setup.exe --uninstall.

2. Підключення плати до ПК

Helmy може працювати з Agent двома способами. Вони не потрібні одночасно: якщо вставлено USB-кабель, Agent користується ним, а Bluetooth вмикається, коли кабель вийнято.

Спосіб А. USB-кабель (найпростіший)

  1. Вставте кабель із передаванням даних (не лише для зарядки) у USB-порт плати й у ПК.
  2. Agent знайде плату сам. На його головній сторінці з'явиться «Helmy на зв'язку» і транспорт «USB».
  3. На платі одразу з'являться дані ПК (екран «Монітор ПК»). Кабель ще й заряджає акумулятор.

Спосіб Б. Bluetooth (без кабелю)

Потрібен ПК з Bluetooth 4.0+ (Windows 10/11) і увімкнений Bluetooth у налаштуваннях плати. Спарювання робиться один раз.

  1. На платі відкрийте Меню → Налаштування → Підключення (або «Меню → Bluetooth»). Торкніться плитки «Bluetooth з ПК — тап — спарити». Плата покаже шестизначний PIN і чекатиме 5 хвилин.
  2. В Agent відкрийте Налаштування → Підключення, у блоці Bluetooth введіть PIN і натисніть «Спарити».
  3. Agent підтвердить підключення: на головній буде «на зв'язку», транспорт «Bluetooth». Надалі плата підключатиметься автоматично, щойно ПК поряд, а кабель вийнято.

Bluetooth повільніший за USB, тому великі дані (оновлення прошивки) йдуть довше. Якщо спарювання «зламалось» (Windows і плата пам'ятають різне), на платі торкніться плитки спарювання ще раз, щоб отримати новий PIN, і повторіть крок 2.

3. Wi-Fi плати

Wi-Fi плата використовує сама, без ПК: для погоди, інтернет-радіо, перевірки Twitch і точного часу. Підтримується лише мережа 2,4 ГГц.

  • Через Agent (зручно): Налаштування → блок «Wi-Fi Helmy». Кнопка «Мережа цього ПК» підставляє назву поточної мережі, введіть пароль і натисніть «Додати на Helmy». Тут же видно мережі плати, можна підключитись до іншої чи видалити зайву. Працює, коли плату підключено по USB або Bluetooth.
  • На самій платі: Меню → Налаштування → «Wi-Fi мережі».

6. Кнопки й програми

  1. Відкрийте в Agent сторінку Кнопки. Виберіть сторінку (їх 3) і клавішу.
  2. Задайте назву, значок і дію: гаряча клавіша, текст, програма (кнопки «Огляд», «Встановлені», аргументи), сайт, медіа, живлення або макрос.
  3. Макрос — кроки через ;: гаряча клавіша, wait 500, text:привіт, url:https://…, media:play (до 20 кроків).
  4. Збережіть: розкладка одразу піде на плату, меню «Кнопки».

Сторінка Програми працює так само, але простіше: оберіть програми зі списку встановлених — вони з'являться в меню «Програми» на платі (по 9 на сторінці).

7. Сповіщення й Twitch

Сповіщення Windows

  1. У Windows мають бути увімкнені сповіщення: «Параметри → Система → Сповіщення». Без цього Windows їх не показує, а Agent нічого не бачить.
  2. В Agent: Сповіщення → «Пересилати сповіщення Windows на Helmy». Можна вимкнути окремі програми у фільтрі «Не пересилати від програм».
  3. Нові сповіщення з'являються на платі коротким банером, а також у списку «Сповіщ.» (свайп праворуч).

Twitch: хто почав стрім

  1. Плата має бути підключена до Wi-Fi (розділ 3) — Twitch вона перевіряє сама.
  2. В Agent: Сповіщення → «Увійти через Twitch». Agent відкриє twitch.tv/activate і покаже код — введіть його й підтвердіть доступ. Agent паролів не бачить і токенів не зберігає: токен передається на плату.
  3. Плата кожні 30–300 секунд (налаштовується в «Меню → Twitch → Налаштування») перевіряє канали, на які ви підписані, і показує плашку, коли хтось починає стрім. Можна вказати окремий список каналів.

8. Оновлення прошивки через Agent

  1. Підключіть плату (USB або Bluetooth). Рекомендується USB: швидше й надійніше.
  2. В Agent: Налаштування → блок «Прошивка Helmy». Там видно версію на платі й версію в Agent та підказку «Є новіша прошивка».
  3. Натисніть «Оновити прошивку». На платі з'явиться прогрес. Не вимикайте плату й не закривайте Agent: по USB це хвилина-дві, по Bluetooth довше.
  4. Плата перевірить контрольну суму й цифровий підпис (чужу чи пошкоджену прошивку вона не прийме) і сама перезапуститься. Заряд має бути від 25% або плату підключено до живлення.

Нову версію Agent з новою прошивкою ви отримуєте, коли встановлюєте свіжий Helmy-Setup.exe.

Не знайшли відповіді? Напишіть на пошту підтримки внизу сторінки й додайте файл журналу Agent (теку відкриває кнопка в сторінці «Журнал»).

1. Install Helmy Agent

  1. Download Helmy-Setup.exe from the home page.
  2. Run it. If Windows shows the blue SmartScreen window, click “More info” → “Run anyway” (the program is not yet signed by a publisher certificate).
  3. Keep the default options in the wizard (shortcuts and start with Windows). No administrator rights are needed.
  4. The Agent starts and lives in the tray. Closing its window only hides it; to quit completely use the tray icon → “Exit”.

To update the Agent just run a newer Helmy-Setup.exe — it replaces the old version and keeps your settings. To uninstall use “Apps” in Windows settings or Helmy-Setup.exe --uninstall.

2. Connecting the board to the PC

Helmy talks to the Agent in two ways. They are not used at the same time: with a USB cable plugged in the Agent uses it, and Bluetooth takes over when the cable is out.

Option A. USB cable (simplest)

  1. Plug a data-capable cable (not charge-only) into the board and the PC.
  2. The Agent finds the board by itself. Its home page shows “Helmy connected” with transport “USB”.
  3. The board immediately shows PC data (“PC monitor”). The cable also charges the battery.

Option B. Bluetooth (wireless)

You need a PC with Bluetooth 4.0+ (Windows 10/11) and Bluetooth turned on in the board's settings. Pairing is done once.

  1. On the board open Menu → Settings → Connection (or “Menu → Bluetooth”). Tap the “Bluetooth to PC — tap to pair” tile. The board shows a six-digit PIN and waits for 5 minutes.
  2. In the Agent open Settings → Connection, type the PIN in the Bluetooth block and press “Pair”.
  3. The Agent confirms: the home page says “connected”, transport “Bluetooth”. From then on the board connects automatically when the PC is near and the cable is out.

Bluetooth is slower than USB, so large transfers (firmware update) take longer. If pairing gets out of sync (Windows and the board remember different things), tap the pairing tile on the board again to get a new PIN and repeat step 2.

3. The board's Wi-Fi

The board uses Wi-Fi on its own, without the PC: for weather, internet radio, Twitch checks and exact time. Only 2.4 GHz networks are supported.

  • Via the Agent (easiest): Settings → “Wi-Fi Helmy”. “This PC's network” fills in the current network name; enter the password and press “Add to Helmy”. The same block lists the board's networks, lets you switch or delete them. Works while the board is connected by USB or Bluetooth.
  • On the board: Menu → Settings → “Wi-Fi networks”.

In Settings the permissions are separate switches: quick keys, mouse and keyboard control, power, etc. A switched-off permission means the board cannot perform that action.

6. Keys and programs

  1. Open the Agent's Keys page. Pick a page (there are 3) and a key.
  2. Set a name, icon and action: hotkey, text, program (Browse / Installed buttons, arguments), website, media, power or macro.
  3. A macro is steps separated by ;: hotkey, wait 500, text:hello, url:https://…, media:play (up to 20 steps).
  4. Save: the layout goes to the board right away, menu item “Quick keys”.

The Programs page is simpler: choose programs from the installed list — they appear in the board's “Apps” menu (9 per page).

7. Notifications and Twitch

Windows notifications

  1. Windows notifications must be on: Settings → System → Notifications. If they are off Windows shows nothing and the Agent sees nothing.
  2. In the Agent: Notifications → “Forward Windows notifications to Helmy”. Mute individual programs in “Do not forward from apps”.
  3. New notifications appear on the board as a short banner and in the “Alerts” list (swipe right).

Twitch: who just went live

  1. The board must be on Wi-Fi (section 3) — it checks Twitch by itself.
  2. In the Agent: Notifications → “Sign in with Twitch”. The Agent opens twitch.tv/activate and shows a code — enter it and approve access. The Agent never sees your password and does not store tokens: the token is handed to the board.
  3. Every 30–300 seconds (set in “Menu → Twitch → Settings”) the board checks the channels you follow and shows a banner when someone goes live. You can also give your own channel list.

8. Updating the firmware from the Agent

  1. Connect the board (USB or Bluetooth). USB is recommended: faster and more reliable.
  2. In the Agent: Settings → “Helmy firmware”. It shows the version on the board and in the Agent, and “A newer firmware is available”.
  3. Press “Update firmware”. The board shows progress. Do not power off the board or close the Agent: a minute or two over USB, longer over Bluetooth.
  4. The board checks the checksum and the digital signature (it rejects foreign or damaged firmware) and restarts by itself. The battery must be at 25%+ or the board on external power.

You get a new Agent together with new firmware when you install a fresh Helmy-Setup.exe.

9. Troubleshooting

ProblemWhat to do
Agent does not see the board over USBUse a data cable; try another port; make sure no other program holds the board's port (terminals, Arduino IDE); look for “COM… busy” in the Agent's Log.
Bluetooth does not connectTurn Bluetooth on at the PC and the board (quick settings); unplug the USB cable; get a new PIN on the board and pair again; if that fails remove the “Helmy” device in Windows Bluetooth settings and pair from scratch.
No Windows notificationsTurn on Windows notifications (section 7); make sure the app is not muted; the board must be “connected”.
Twitch shows an errorCheck the board's Wi-Fi (the Connection screen should say “ready”) and sign in to Twitch from the Agent again. If the screen says “New sign-in needed”, sign in again.
Wi-Fi does not connectOnly 2.4 GHz is supported; check the password (8–63 characters).
PC data does not updateCheck “PC data” on the Agent's home page. Some sensors (e.g. CPU temperature) are only available when the Agent runs as administrator.
Windows or an antivirus warns about the programThe program is not yet signed with a publisher certificate. Compare the file's SHA-256 with the one on the home page.
